# es6-fantasy-forge

This project practices ES6 JavaScript classes by creating a Hero object
with health and mana attributes and methods that modify those values.

## Concepts Used

ES6 Classes
Constructors
Methods
The `this` keyword
Object instantiation with new

## How It Works

A Hero is created with a name, health, and mana.
The `rest()` method restores health and mana.
The `takeDamage()` method reduces health.

## TypeScript

npm run build
